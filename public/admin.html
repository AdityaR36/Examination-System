Prototype security note

This is a development prototype, not a production-ready examination system.

The demo admin sign-in is client-side and uses a demonstration credential. API routes for administration are not protected by production-grade server-side authentication, and prototype data is stored locally. Before real institutional use, add server-side role-based access control, secure password hashing, session management, audit logs, backups, and appropriate data-protection safeguards.
